# DiffMerge

WinMerge 스타일의 파일 비교/병합 VSCode 확장.

## 특징

- **파일 1개만 열어도 동작** — 반대쪽은 빈 상태로 비교 (Meld처럼 2개 강제 아님)
- **드래그앤드롭** — Finder·바탕화면은 그대로 패널에 드롭. VSCode 탐색기에서는 ① 사이드바(⇆) 왼쪽/오른쪽 슬롯에 드롭(Shift 불필요, 권장) 또는 ② 패널에 직접 드롭 — 이때는 **드래그를 시작한 뒤, 놓기 직전에 Shift** 를 눌러야 함 (미리 누르면 안 됨 — VSCode 워크벤치 제약, vscode#182449)
- **오버뷰 룰러** — 오른쪽 끝 세로 막대에 파일 전체의 변경 위치 표시 (WinMerge 위치 창). 클릭/드래그로 점프
- **텍스트 붙여넣기 비교** — 파일 없이 패널에 그냥 붙여넣기(⌘V)하면 빈 쪽부터 채워짐. 툴바 `✎ 텍스트` 버튼으로 좌/우 텍스트를 직접 입력·수정 (⌘Enter 비교, Esc 취소)
- **F5 또는 ⟳ 비교 버튼** — 디스크에서 다시 읽어 재비교
- **블록 단위 병합** — 변경 블록마다 ▶ / ◀ 버튼으로 좌→우, 우→좌 복사 후 저장
- 탐색기 우클릭 → **"DiffMerge로 비교"** (1개 또는 2개 선택)
- 변경 블록 이전/다음 탐색 (F8 / Shift+F8), 좌우 바꾸기, 줄 내부 변경 하이라이트

## 사용법

1. 명령 팔레트 → `DiffMerge: 비교 창 열기` 또는 탐색기에서 파일 우클릭 → `DiffMerge로 비교`
2. 패널에 파일을 드래그하거나 각 패널의 `열기…` 버튼 사용
3. 파일이 바뀌면 `F5` 로 재비교

## 제한

- 인코딩은 UTF-8 기준 (EUC-KR 등은 깨져 보일 수 있음)
- Finder에서 드롭한 파일이 경로 정보를 제공하지 않는 환경에서는 비교는 되지만 F5 재읽기가 불가능 (내용 스냅샷으로 동작)

## 설치

```bash
code --install-extension diffmerge-0.1.0.vsix
```
